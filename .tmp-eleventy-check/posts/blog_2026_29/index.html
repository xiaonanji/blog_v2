详细报道与点评 #

中国Moonshot AI推出全球最大开源模型Kimi K3 #

近日，Moonshot AI发布了包含2.8万亿参数、百万令牌上下文窗口的多模态开源大模型Kimi K3。该模型在多个专业基准测试中接近甚至超越部分顶尖闭源AI，尤其在前端编码领域表现卓越。该事件被视为中国开源AI与美国顶尖技术差距缩小的重要标志，业界同时关注其算力消耗及部署难度。此举也使西方实验室重新审视其算力优势的持续性，对出口管制政策产生冲击。

OpenAI自动化红队系统GPT-Red上线 #

OpenAI发布大型语言模型安全测试工具GPT-Red，能通过自我对抗学习自动发现模型漏洞和提示注入攻击，极大提升安全性和模型对齐度。此系统已辅助强化了最新GPT-5.6版本的鲁棒性，体现了人工智能安全领域自动化测试技术的发展趋势，预计未来将成为AI安全防护的重要基础设施。

美国Thinking Machines发布Inkling开源多模态模型 #

Thinking Machines推出9750亿参数的Inkling系列基础大模型，支持文本、图像和音频输入，采用高效Mixture-of-Experts架构，获得业界多方支持。尽管Inkling性能略逊于中国顶尖开源模型，但其Apache 2.0许可证和丰富的生态系统建设彰显美国开源AI的发展实力。

OpenAI Codex用户规模激增，成为编码AI领军产品 #

2026年上半年内，OpenAI Codex用户数量激增超十倍，达到700万人，超过主要竞争者Claude Code。OpenAI同步发布GPT-5.6 Sol，针对性能和安全性做升级。Codex的快速增长展示了开发者和企业对智能编码工具的强烈需求。

谷歌更名NotebookLM为Gemini Notebook，扩展功能融合生态 #

谷歌更新其智能笔记应用，强化云端代码执行能力及与多款第三方应用的整合，便利用户在搜索时直接操作购物、设计和音乐等任务，进一步推动多模态和生态互联体验的发展。

AWS计费系统故障致客户账单暴涨事件 #

亚马逊云服务因计费子系统出错，导致部分客户账单从几分钱骤增至数十亿美元甚至万亿美元级别。AWS正回滚更新并暂停实时计费，受影响客户无需主动操作。此事件凸显云服务复杂计费结构带来的潜在风险。

美国野火浓烟蔓延严重，部分城市空气质量骤降 #

加拿大及美国多地失控野火产生的浓烟随季风扩散至美国中西部及东海岸，导致芝加哥、纽约、华盛顿等大城市空气污染严重。多地发布空气质量预警，专家建议居民佩戴N95口罩并减少户外活动。

GPT-5.6全权限模式存在用户文件误删隐患 #

OpenAI透露，最新GPT-5.6版本在“全权限模式”中偶尔会因环境变量处理错误，误删除用户文件。官方强调错误罕见且不应发生，正加紧更新文档和安全措施，以防止数据损失。

Meta计划向Anthropic出售闲置AI算力 #

Meta正与Anthropic洽谈租赁其数据中心空闲计算资源，金额可能达100亿美元，为期两年。此举不仅为Meta开辟新的收入渠道，也体现了AI算力市场日益紧张及大型模型运行成本的巨大压力。

美国隐孢子虫疫情持续扩散，生食蔬菜安全成焦点 #

美国30多个州检测到Cyclospora寄生虫爆发，感染人数远超官方数据。疫情疑与生菜及沙拉链渠道相关，多家连锁餐厅客流及股价受影响。专家呼吁公众理性对待，注重食物清洁和就医检测。
